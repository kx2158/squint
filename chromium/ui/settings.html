Privacy & network

Hide what I visit from my network Sends everything through Tor, so Wi-Fi owners and your internet provider cannot see which sites you open
Without this, your internet provider can see every server you connect to, even though pages are encrypted. With it on, they only see that you use Tor. Pages load slower and some sites ask for more captchas. Turn it off to browse directly, or pick a VPN under Route below. Encrypted DNS and encrypted site names (ECH, where the site supports it) are always on for direct connections.
Resist fingerprinting Canvas, WebGL, audio, time zone, screen, hardware and language all look the same for everyone
Sites can recognise you without cookies by measuring tiny differences in your graphics, sound, fonts and settings. This makes the browser report one generic Windows Chrome: UTC time zone, English, a 1920x1080 screen, 8 cores, fixed graphics name, and slight noise in canvas and audio readouts. Reload open tabs after changing it. Honest limits: installed fonts and web workers are not covered, so it lowers uniqueness a lot but is not the same as Tor Browser.
Canvas readback What sites get when they read back what they drew
Drawing a hidden picture and reading it back is the most common fingerprint. Blank gives every site an empty picture of the right size, the same for everyone. It can break sites that save or crop pictures from a canvas, like QR makers or avatar croppers. Noise keeps those working but gives you a value no one else has.
Software graphicsWebGL and canvas are drawn by the CPU, so your graphics card cannot be told apart. Slower on 3D pages. Restart Squint after changing.
Letterbox windowPage area is rounded to fixed steps, so your exact window size stays private. Leaves thin empty margins.
Block WebRTCStops video-call code from revealing local network addresses. Turn off if you need browser calls.
Route Where your internet traffic goes before it reaches a site
What is routing? Every page you open travels from this computer to the website. The route decides who can see that trip.

Direct

The Wi-Fi owner can see which servers you connect to. The sites see your real IP address and rough location.

Proxy / VPN

The Wi-Fi owner only sees one connection to your VPN or proxy. Sites see the VPN's address. The VPN company can see what the Wi-Fi owner used to see, so pick one you trust.

Tor

Traffic hops through three volunteer servers. The Wi-Fi owner sees that you use Tor, sites see an exit server. Strongest privacy, but slower.

If it breaks

Proxy and Tor fail closed: if the proxy or Tor is down, pages simply fail to load instead of silently going direct.
Send the whole PC through Tor Other programs use Squint's Tor too. Off until you turn it on. Needs the Tor route.
Squint runs its own Tor and tells Windows to use it as the system proxy. Browsers, Discord, many updaters and most apps that follow the Windows proxy setting then go through Tor, and their web addresses are looked up by Tor. Honest limits: apps that ignore the Windows proxy (many games, some launchers, anything using UDP or its own network code) still connect directly, and Tor only carries web-style TCP traffic. It hides your IP and your traffic from your network and provider. It does not change what a browser fingerprint looks like. Squint puts your old proxy setting back when you turn this off or close Squint. If the internet ever stops after a crash, run scripts\restore-network.bat.

Encrypted DNS Hides which site names you look up from the network
What is DNS? Before a page loads, your computer asks a DNS server "what is the address of example.com?". Normally that question is sent in plain text, so the Wi-Fi owner reads a list of every site you visit.
  • Encrypted DNS wraps the question so the network cannot read it.
  • Quad9 also refuses known malware sites. Cloudflare is usually a little faster.
  • The DNS company sees the lookups, but not the pages.
  • With a Proxy/VPN or Tor route this setting is not used, because the proxy looks the names up for you.
HTTPS only Upgrades every address to a secure connection
HTTPS encrypts the page between you and the site, so the network cannot read passwords or content. Plain http is readable by anyone on the same Wi-Fi. A few old sites only speak http - turn this off for them.

Ask before using passwords Needed to view the list, show, copy or fill a password
Unlocking uses Windows Hello (PIN, fingerprint or face) or your own passcode. Once unlocked it stays open for two minutes, then locks again. Windows Hello needs a PIN set in Windows Settings, Accounts, Sign-in options. If it does not appear on your PC, use a passcode - it always works.

Content filter

Block adult content Adult sites and the ads that promote them
Uses public blocklists of adult sites and of the ad networks that serve adult ads. Blocked sites show a notice instead of loading, and adult ads on normal pages are cut before they appear. Search engines are switched to their strict safe-search mode. Lists are never perfect: new sites appear daily, so update now and then.
Blocklist
Hide posts with these words On every site: social media, forums, comments, video lists
One word or phrase per line, or separated by commas. Any post, comment or video card that contains a word is hidden on the page, on all sites. Whole words only, upper or lower case does not matter. It knows the layout of the big sites (X, Reddit, YouTube, TikTok, LinkedIn, Mastodon) and the generic article tag, so on unusual sites a word may hide a whole article or nothing. Pages reload when you change the list.
Never load these sitesDomains, one per line. Subdomains are blocked too.
